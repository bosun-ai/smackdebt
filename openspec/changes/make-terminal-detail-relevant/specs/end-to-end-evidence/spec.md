## MODIFIED Requirements

### Requirement: Terminal evidence is exact and stable
The system SHALL compare committed exact terminal bytes for dense repository,
package, directory, and file views in default and `--all` modes at widths 120,
100, 80, and 50. Evidence SHALL cover same-scope relevance, default limits,
useful-debt expansion, stable rank, non-primary/advisory qualifiers, three
architecture findings with closed witnesses, actionable history ending `not
linked in code`, grouped warnings, one discover command, one visit per unique
linked typed ID in the rendered scope, no empty sections, and absence of every
excluded family and old dependency phrase.

Each reviewed dense default public codebase and selected package, directory,
and file path result at widths 120, 100, and 80 SHALL contain at most 60
nonempty lines. Each reviewed default width-50 result SHALL contain at most 100
nonempty lines. `--all` SHALL have no nonempty-line budget and SHALL retain
every linked useful-debt row. Exact glyph, styling, ANSI-stripped
equality, display-width, and zero safety-fallback evidence from the verdict
change SHALL remain.

#### Scenario: Dense scope matrix renders
- **WHEN** every named scope and detail mode renders at every required width
- **THEN** exact snapshots meet selection, unique-link, absence, closed-witness, command, and nonempty-line expectations without losing useful evidence

#### Scenario: Styling policy is compared
- **WHEN** forced and disabled color render the revised dense views
- **THEN** only status glyphs are styled and ANSI stripping reproduces exact plain text

### Requirement: Public command evidence covers every revised decision
Exact acceptance SHALL cover default and `--all` repository, package,
directory, and file flows for five debt-bearing areas, three ranked source
findings, three architecture findings with closed witnesses, three actionable
history findings, grouped warnings, one discover command, and empty-section
absence. `--all` SHALL prove limit removal only for linked useful-debt families.
Path SHALL prove scope-only behavior. Text audits SHALL reject raw resolved,
ownership, external, unmatched, ambiguous, weak/explained history, activity,
concentration, history coverage/processing, healthy, repeated-row, empty-section,
and `no code dependency` output.

Exact JSON version-3 bytes SHALL validate schema, indexes, completeness, and
privacy from the same fixtures. Serial/automatic terminal and JSON bytes,
status, streams, report facts, analysis, rank, work counters, allocations, and
resource profiles SHALL remain unchanged. Instrumented pure and complete flows
SHALL prove one-pass selection through existing links with no project work,
large clones, de-dup allocation, identity mapping, second selected-ID
collection, or repeated per-row global scans. Report/index integrity tests SHALL
reject a duplicate typed ID within one scope owning list before rendering.
Accepted current fixtures SHALL prove their owning lists are already unique and
retain exact JSON bytes without a silent rewrite.

#### Scenario: Human output is audited
- **WHEN** snapshots, help, README examples, and selection tests are checked
- **THEN** required useful debt appears once and every excluded or stale human phrase remains absent

#### Scenario: Machine and work output is audited
- **WHEN** revised terminal flows run through the public matrix
- **THEN** JSON, schema, indexes, privacy, serial/automatic bytes, one-visit renderer work, allocation, and resource evidence remain unchanged

#### Scenario: Duplicate owning link is injected
- **WHEN** negative report/index integrity proof runs
- **THEN** it fails before rendering and renderer allocation evidence shows no de-dup structure exists

### Requirement: Three workload families have privacy-safe acceptance
After public proof passes, aggregate read-only review SHALL cover self, a
private mixed application, and a private Rust workspace. Each review SHALL
record only whether default and `--all` show useful debt, excluded raw/context
families are absent, completed owning links render once, optional sections are nonempty when
present, selected default paths meet their line budgets, `--all` includes all
useful debt, and JSON remains complete. Committed
evidence SHALL name only workload family and outcome categories and SHALL
contain no private name, path, source, Git identity, history, or raw terminal
output.

#### Scenario: Self is reviewed
- **WHEN** default and `--all` output are inspected read-only
- **THEN** selected default paths meet line budgets and `--all` includes every useful-debt row with zero excluded raw/context rows and no repeated fact or section

#### Scenario: Private mixed application is reviewed
- **WHEN** default and `--all` output are inspected read-only
- **THEN** selected default paths meet line budgets and `--all` retains all useful primary application debt with zero excluded raw/context rows

#### Scenario: Private Rust workspace is reviewed
- **WHEN** default and `--all` output are inspected read-only
- **THEN** selected default paths meet line budgets and `--all` retains all useful Rust findings and closed witnesses with zero weak-history or raw-graph rows
