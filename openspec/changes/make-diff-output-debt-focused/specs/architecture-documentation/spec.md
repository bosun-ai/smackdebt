## MODIFIED Requirements

### Requirement: Architecture documentation separates analysis and presentation
`ARCHITECTURE.md` SHALL assign source, architecture, and evolution comparison
classification, stable rank, one private per-scope `DebtDiffSelection`, three
unique typed lists, source-only `DebtDiffCounts`, unique changed-file warning
aggregation, and index integrity to analysis/report assembly. It SHALL
assign one-pass borrowed selection and content-aware layout to terminal output.
It SHALL state that output directly consumes the completed selection and does
not apply trust policy, reclassify, scan
global comparison tables, allocate identity maps or second selected
collections, silently repair data, or perform project work. It SHALL state that
all complete facts remain serialized exactly in JSON version 3 while the new
selections and counts stay private and nonserialized. It SHALL state that
fixture, generated, and recovered comparisons remain JSON-only in diff default,
diff `--all`, and diff path while selected recovered facts produce only the
exact grouped real warning. Codebase role/advisory detail behavior SHALL remain
unchanged. It SHALL document
that architecture/history IDs never enter source `QUALITY`, `AREAS`, or discover
guidance.

#### Scenario: Maintainer traces one diff row
- **WHEN** they read the architecture document
- **THEN** they can follow analysis fact to its typed list and one terminal visit without crossing responsibility seams or combining non-source findings into source counts

#### Scenario: Integrity receives a repeated typed-list ID
- **WHEN** one private source, architecture, or evolution list repeats a typed ID
- **THEN** documentation routes failure to report/index validation rather than output cleanup
